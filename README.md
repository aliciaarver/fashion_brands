# Atelier Index

MVP PWA-каталога fashion-брендов. Один Nuxt-проект содержит публичный каталог, серверное API и административную форму. Данные хранятся в PostgreSQL.

## Быстрый запуск

```bash
docker compose up --build
```

После запуска:

- каталог: http://localhost:3000
- добавление бренда: http://localhost:3000/admin/brands/new
- PostgreSQL на хосте: localhost:54329

Первый запуск создаёт таблицы. Демонстрационные бренды больше не добавляются — каталог пуст, пока администратор не добавит свои бренды через `/admin/brands/new`.

## Запуск приложения на хосте

```bash
docker compose up -d db
cp .env.example .env
npm install
npm run dev
```

## Текущий вертикальный срез

- адаптивный каталог;
- фильтры по стране, категории, стилю и цене;
- страницы брендов;
- произвольные внешние ссылки бренда;
- регистрация и вход по email/паролю (`nuxt-auth-utils`), выход;
- личная библиотека: сохранение/снятие бренда, фильтры, отложенное сохранение после входа;
- форма создания и публикации бренда (доступна только роли `admin`);
- PWA manifest и service worker;
- Docker Compose и PostgreSQL;
- схема подборок (без API и страниц — следующий срез).

### Как выдать роль администратора

1. Зарегистрируйтесь через `/register`.
2. Выполните в базе: `UPDATE users SET role = 'admin' WHERE email = 'ваш@email';`
3. Перелогиньтесь — после этого в навигации появится пункт «Добавить бренд» и откроется `/admin/brands/new`.

Подборки, загрузка изображений в S3 и аналитика идут следующим срезом.
